Accessibility

Our goal is a website that is understandable, navigable, and usable across devices and assistive technologies.

This redesign includes semantic landmarks, keyboard-accessible navigation and accordions, visible focus behavior, form labels, a skip link, responsive layouts, and reduced-motion support.

Before launch, run a final WCAG audit with Lighthouse, axe, or WAVE and test key pages with keyboard-only navigation and a screen reader.

If you encounter a barrier, contact Redwood Horizon so we can work to address it.
